Прочитай файл task.md в корне проекта. Это техническое задание.

Твоя задача — провести ресерч, НЕ писать код.

## Шаги

1. Прочитай task.md целиком
2. Определи стек по проекту (composer.json, go.mod, Dockerfile и т.д.). Используй знания AGENTS.md для того чтобы сэкономить токены
3. Найди все файлы, которые затрагивает задача:
   - Контроллеры/хендлеры
   - Сервисы
   - Сущности/репозитории
   - Миграции
   - Тесты
   - Конфиги (routes, services)
4. Прочитай найденные файлы, пойми текущую логику
5. Обозначь зависимости между компонентами
6. Выяви потенциальные проблемы или неясности в ТЗ

## Результат

Создай файл task-research.md в корне проекта со структурой:
```
# Ресерч задачи

## Понимание задачи
(Своими словами, что нужно сделать)

## Стек
(Определённый стек проекта)

## Затронутые файлы
- path/to/file.php — роль, текущее поведение
- ...

## Зависимости
(Что от чего зависит, какие сервисы вызываются)

## Текущее поведение
(Как работает сейчас то, что нужно изменить)

## Вопросы и неясности
(Если есть)
```

НЕ пиши код. НЕ предлагай решения. Только ресерч.

После создания файла скажи: "Ресерч завершён → task-research.md. Проверь и запускай /plan"
