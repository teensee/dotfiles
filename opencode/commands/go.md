Определи текущий бранч: `git branch --show-current`; если пусто — `git rev-parse --abbrev-ref HEAD`.

Рабочая директория задачи: `.opencode/work/<branch>/`.

Прочитай файлы task.md, task-research.md и task-plan.md из рабочей директории.

Твоя задача — реализовать план. Следуй task-plan.md ТОЧНО. Если план требует корректировки — сначала
скажи об этом и дождись подтверждения.

## Делегирование

Делегируй реализацию специализированным агентам через Task tool по типу работы:

- PHP/Symfony-код, Doctrine, Messenger → symfony-dev
- Go-код, RabbitMQ, HTTP → go-dev
- Python-код, FastAPI, Django → python-pro
- Rust-код → rust-engineer
- Zig-код → zig-dev
- SQL, миграции, индексы → dba
- Docker, CI/CD, bash-скрипты → devops
- Написание тестов → test-writer

Один шаг плана = один агент. Если шаг затрагивает несколько областей — раздели на подзадачи и
делегируй каждую нужному агенту.

## Правила

1. Выполняй шаги из task-plan.md последовательно
2. После каждого значимого шага — краткий статус что сделано
3. Следуй стилю и паттернам существующего кода
4. Запусти тесты после реализации
5. Если тесты падают — почини

## Результат

После завершения создай/обнови файл task-log.md в рабочей директории задачи:

```
# Лог реализации

## Дата
(timestamp)

## Созданные файлы
- path/to/new/file — описание

## Изменённые файлы
- path/to/changed/file — что изменено

## Миграции
- (если были)

## Тесты
- Результат прогона: OK / FAIL
- Какие тесты добавлены/изменены

## Заметки
(Если отступил от плана — почему)
```

После завершения скажи: «Реализация завершена → task-log.md. Проверь изменения через git diff и
запускай /review».
